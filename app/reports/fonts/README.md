Unmodified WenQuanYi Micro Hei 0.2.0-beta, distributed under the Apache 2.0 option of its upstream dual license. See LICENSE-Apache-2.0.txt, COPYRIGHT.txt and UPSTREAM-README.txt. Font provenance, SHA-256 and validation details are recorded in docs/FONT_LICENSING.md.

Keep this directory in both Windows packages. PDF code loads it from RESOURCE_DIR so the onefile extraction directory is supported. Do not replace it with proprietary operating-system font files.
