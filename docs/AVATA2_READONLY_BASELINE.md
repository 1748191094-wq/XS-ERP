# DJI Avata 2 正常机只读基线

记录时间：2026-07-22

## 约束

该设备由用户明确指定为完全正常的基准机。本轮只读取 Windows 已缓存的 PnP、驱动、网络和文件系统元数据：

- 未打开 MI_03 至 MI_07 的 Bulk 接口。
- 未 claim USB 接口，未读取 Bulk 端点，未发送 DUML。
- 未执行 ADB、Fastboot、刷机、标定或网络探测。
- 未修改、复制或删除设备存储中的文件。

## 已确认的本机枚举

- USB 厂商/产品 ID：`VID_2CA3 / PID_0020`。
- 设备形态：USB Composite Device，修订号 `0504`。
- MI_00：Remote NDIS，Windows 自动地址为 `169.254.15.21/16`；缓存中没有对端 ARP 项。
- MI_02：USB Mass Storage，包含两个逻辑单元。
- MI_03 至 MI_07：厂商自定义 Bulk 接口，类为 `ff/43/01`，绑定 `libusb-win32 5.0.0.7`。
- Windows 暴露的序列字符串为占位值 `123456789ABCDEF`，不得当作真实设备序列号。

## 存储基线

- 逻辑单元 0：`InternalStorage`，exFAT，约 46.1 GB，总空闲约 43.1 GB。
- 逻辑单元 1：无介质/未就绪。
- 顶层目录：`MISC`、`DCIM`。
- 媒体索引：`MISC/FC8485.db`，SQLite 数据库版本 12。
- 数据库记录 11 组 MP4/LRF 媒体，摄像头型号字段为 `DJI FC8485`。
- 当前挂载存储中未发现 DAT 或飞控日志；`FC8485.db` 是媒体索引，不是飞控日志。

## 静态工具研究结论

对本机第三方程序只做字符串静态检查，未执行程序。可见其通信实现会：

1. 枚举 DJI USB 设备与配置描述符。
2. 查找带输入/输出端点的 Bulk 接口。
3. 打开并 claim 接口，设置 alternate setting。
4. 建立双向收发并传输 DUML。

从第 3 步开始会主动接触设备，因此不属于本轮“只读发现”范围。当前实现只读取 Windows PnP 与注册表缓存，不复用该工具的 RPC、代码或传输实现。

## 后续安全路径
