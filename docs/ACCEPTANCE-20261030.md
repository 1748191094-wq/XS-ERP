## 发现问题

P2：报价读取定损成功后，仍显示“重试读取定损”按钮。

复现：完成定损 → 点击“核对并创建报价” → 等待结论与预估费用带入。期望成功后不显示重试入口；实际按钮仍可见。app/static/app.js 对 #quote-assessment-retry 添加 hidden 类，但 app/static/styles.css 只有特定组件的 hidden 规则，没有覆盖该按钮的规则。已有前端行为测试检查类名，无法检出实际 CSS 可见性。应补真实浏览器可见性回归，修复后复验成功隐藏、失败出现、请求中禁用和重试焦点。

手机弹窗背景文字透出，影响阅读清晰度，列为视觉改进项；不据此推断其他平台均有相同效果。
