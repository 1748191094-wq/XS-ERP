# 旧项目迁移映射与安全基线

## 迁移输入

旧库、历史 PDF、Excel 和本机配置均不包含在本交付中。管理员如需迁移，应自行选择有权处理的数据源，并在离线副本上先完成完整性检查和备份。

## 字段映射

| 旧字段类型 | 新结构 | 处理原则 |
|---|---|---|
| 报价编号 | `quotes.quote_no` | 保留原编号并校验唯一性 |
| 客户名称、电话、邮箱 | `customers` | 电话优先匹配，缺失值保持为空 |
| 设备型号、序列号 | `drone_devices` | 无效序列号生成可追溯临时编号 |
| 故障、备注、状态 | `repair_orders`、`quotes` | 保留原始语义，不推断缺失状态 |
| 人工费、项目、总额 | `quotes`、`quote_items` | 保存历史金额快照，不按当前价格回算 |
| 历史 PDF | `attachments` | 仅迁移可验证关联的文件 |
| 工程师、Logo、二维码 | 对应账号或品牌设置 | 无可靠映射时留空并人工处理 |
| 创建时间 | 各业务表时间字段 | 仅回填可确认的原始时间 |

## 安全规则

1. 迁移前使用 SQLite 在线备份并执行 `PRAGMA integrity_check`。
2. 不修改、不删除源数据库和历史附件。
3. 不迁移密码、SMTP 授权码、令牌或其他本机秘密。
4. 不把旧报价自动视为收款，不凭空补齐采购成本或客户归属。
5. 无法映射的记录写入本地迁移报告，等待管理员人工确认。
6. 所有数据库结构变化使用 Alembic，正式库不得手工改表。

## 交付状态

本源码包不附带任何迁移输入、备份、迁移报告或业务记录。迁移工具只提供代码能力，必须由管理员在自有数据副本上显式执行。
