# 客户端服务进度改版

参考用户提供的服务查询、时间线、报价截图，改造 `/client/work-orders`。保留自有品牌和既有登录后客户归属校验，不接入其他品牌服务。

- 白底、浅灰案例卡片、蓝色操作入口；支持手机单列与桌面双列。
- 按服务类型、全部案例/待处理/进行中/历史案例筛选，按本账号工单号或产品名称搜索。待处理指需要客户行动，而非内部待办；不提供未经验证的手机号/邮箱公开查询。
- 维修详情突出真实当前状态及下一步说明。时间线仅展示后端实际历史，不推算完成节点或日期。
- 服务信息包含工单号复制、设备、脱敏 SN/姓名、申请时间、送修方式和故障描述。
- 报价包括检测结论、维修方案、项目、服务费、运费、优惠、合计与客户注意事项。下载使用原有客户鉴权 PDF 接口。
- 接受/拒绝报价增加二次确认和提交锁；仅当前为报价待确认且报价未处理时显示操作，明确确认不扣款。
- 列表/详情失败可重试，详情使用请求序号拒绝过期响应，返回列表保留筛选且恢复键盘焦点。卸载后不再写入详情。
- 修正底部导航首页和订单同时高亮，适配深色模式。

边界：当前接口没有维修物流单号、物流公司、收款状态、公开检测图片或发票字段，本轮不虚构这些内容，也不新增空操作入口。图标替代未提供的设备图片。商城、回收、置换详情保留原有业务功能。无数据库迁移，无 GitHub 推送或部署。

## 验证

- `npm run build --prefix client`：TypeScript 检查及生产构建通过，交付包包含已构建静态文件。
- 全量 pytest：244 passed；两条既有依赖提示。
- Node 既有行为回归：31 passed。
- `tests/client_progress.browser.cjs`：在已构建客户端上使用隔离 API fixtures，320/390/1440 px 验证列表/详情失败重试、状态筛选、搜索与无结果、无横向溢出、下载请求、取消与接受确认、处理后隐藏按钮、返回列表焦点、无页面 JS 异常；不是客户生产数据端到端验收。PDF 内容沿用后端既有测试，浏览器下载测试仅验证下载链路。
- 人工查看中文手机列表、详情及桌面列表截图；截图仅用于内部验收，不纳入源码包。初次浏览器缺中文字体，安装项目自带字体后重新检查。

## 复验

先构建客户端，再执行 `node tests/client_progress.browser.cjs`。需要 Playwright 与 Chromium；可通过 `PLAYWRIGHT_MODULE` 指向 Playwright 模块、`CHROMIUM_EXECUTABLE` 指向浏览器。可选 `SCREENSHOT_DIR` 保存内部截图。测试自行启动本地静态服务，拦截所有 API 使用测试数据，不连接业务数据库。
