# D3 / D8 定损读取失败直接重试

起点 691078b，范围仅为报价预填失败的恢复路径。新增“重试读取定损”按钮，仅读取失败时出现；加载中禁用，成功后隐藏，重复点击不并发请求。保存时的失败提示指向该按钮。

同一工单重试不再清空人工填写的结论、责任、维修建议及报价行。成功后仍按既有规则补入空白结论字段及建议项目，来源 ID 采用该次成功响应；无已完成定损时明确记为无来源。切换工单仍清空旧的预填上下文，沿用请求序号和弹窗有效性保护；关闭后不会开始重试或消费迟到响应。

按钮为 type=button，状态区保留 aria-live；重试成功且焦点仍在按钮时，将焦点移到可程序聚焦的状态说明，避免隐藏控件保留焦点。未改业务状态、金额计算、后端权限或数据库迁移。

前端行为测试共 20 项通过（本轮新增 6 项）：人工结论和项目保留、重复点击抑制、再次失败、重试期间切换工单、关闭后点击、无已完成定损和焦点恢复。使用生产预填闭包、可控 Promise 和模拟 DOM；这些测试不等于真实浏览器视觉验收。完整 pytest 结果见交接记录。

剩余：只读账号的定损入口限制；浏览器桌面/手机、键盘、错误状态和定损到报价完整流程。此前浏览器下载包损坏，本轮未重复安装。A 尚未整体验收，B 未开始；Windows 安装包及实机未验证。
