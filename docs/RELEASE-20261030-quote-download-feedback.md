# 报价下载与工单号复制的就近反馈

起点945b597。客户在长详情页下载报价单失败或复制工单号后，原提示位于整页末尾且两个操作共用状态，容易误以为点击没有反应。本轮将反馈放回操作位置。

实施前阅读Apple官方Feedback指南：https://developer.apple.com/design/human-interface-guidelines/feedback.md 。依据就近状态反馈、文字解释与可恢复操作原则，保留现有报价结构与品牌。

- 复制成功/失败反馈位于工单号旁；剪贴板不可用时显示可手动选择的工单号，兼顾桌面和触屏。
- 下载失败原因及下一步在报价标题下显示，原按钮变为“重试下载报价单”；重试不丢失报价内容。请求中继续禁用按钮。
- 下载成功仅说明已请求浏览器保存并引导查看下载列表，不声称已完成磁盘保存；复制反馈不再覆盖下载状态。
- 操作目标至少44px高，键盘焦点可见，报价标题增加滚动留白避免桌面固定导航遮挡。
