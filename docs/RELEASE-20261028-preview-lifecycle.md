# D3 / D8 报价弹窗关闭后的迟到响应

起点：3ec8f10。只处理定损预填请求在报价弹窗关闭后的生命周期，不扩展业务或改动数据库。

原问题：关闭弹窗只隐藏 DOM，关闭动画期间及动画结束后 source.isConnected 仍然为 true，因此迟到的成功响应会写入已关闭的表单并添加预估项目，失败响应则会弹出无关错误。

修复：成功与失败路径共用有效性判断；只有请求序号、当前表单、所选工单均匹配且弹窗可见、未进入关闭动画时才消费响应。原有来源 ID 冻结、快速切换防串单、人工已填结论保留规则不变。没有后台请求取消或数据库迁移。

验证：新增 tests/quote_preview.test.cjs，用可控 Promise 执行生产代码中的预填闭包；9 个场景覆盖关闭动画、完全隐藏、替换弹窗后的成功/失败响应，以及快速切换、正常错误提示和请求期间人工编辑。旧代码复现 4 个关闭场景失败，修复后全部通过；加上既有报价表单 5 项，共 14 项前端行为测试通过。全量 pytest 结果见交接记录。
