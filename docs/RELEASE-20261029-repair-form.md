# 维修申请表：按填写任务组织信息

从 c4c2b84 接力，上一轮已交付 libfile_d4f1985347508191be4c97c0f67ec14f；本轮无待补交版本。

## 用户问题与改动

原表单将设备、故障、联系与附件字段放在一块，缺少分组，必填/选填不明确，绝大多数标签没有关联控件。用户难以快速了解需要准备什么，点击标签不能定位字段，辅助技术也缺少字段名称。

改为四个有语义的 fieldset/legend 分组：送修设备、故障与设备情况、送修方式与联系信息、补充材料。全部输入控件拥有关联标签；必填字段显示文字标识，选填项明确标注。增加序列号、故障描述的具体填写提示并以 aria-describedby 关联，联系人与电话支持浏览器自动填充。继续复用已有设备和地址选择，不增加业务字段或改变请求数据。

寄回地址缺失说明移到地址附近，提交按钮附近保留简短原因，地址跳转前明确未提交内容不会保存。提交中禁用各字段组，避免用户误认为请求发出后的编辑仍会被提交。桌面限制阅读宽度，手机保持单列；沿用明暗语义颜色与原生控件，提供可见焦点和至少 44px 的设备经历点击区域。

## 设计依据

2026-10-29 阅读 Apple 官方指南及其 `.md` 正文：

- https://developer.apple.com/design/human-interface-guidelines/entering-data ：说明所需信息、复用可得数据、提供选择和必要输入提示。
- https://developer.apple.com/design/human-interface-guidelines/accessibility ：让界面可理解、可感知，支持不同输入方法和清晰标签。

本轮将原则用于已有 Web 表单，不模拟原生应用，不使用 Apple 商标或无业务意义的装饰。
