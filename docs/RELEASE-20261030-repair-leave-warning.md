# 维修申请离开前确认

起点 48a3c54。解决填写设备、故障或选择附件后误点导航，未提交内容无提示丢失的问题。

实施前查阅 Apple 官方 Entering data 指南（https://developer.apple.com/design/human-interface-guidelines/entering-data.md），依据减少输入负担、清晰说明所需操作的原则，保留现有 Web 表单并补齐离开反馈。

## 行为

- 表单与初始化默认值不同或已选择附件时显示未提交提示；站内返回、导航及添加地址前弹出原生确认。取消保留文字与附件，明确确认才离开。
- 创建请求或附件上传过程中离开，提醒结果可能无法确认，建议等待完成；不会宣称中断后一定没有创建工单。
- 原样默认表单不拦截；提交和附件处理结束后恢复正常导航。组件卸载移除窗口事件监听。
- 注册 beforeunload 以请求浏览器在刷新/关闭时提示。浏览器决定文案与是否显示，尤其移动端强制退出无法保证提醒。

## 验证

Vue 类型检查、生产构建及31项既有 Node 行为测试通过。真实 Chromium 隔离 API fixture 的申请页与服务进度/报价脚本在320/390/1440px通过。新增覆盖取消导航后文本和附件保留、上传期间取消离开并继续上传、确认放弃后导航、初始表单与成功页不拦截、卸载清理；在真实浏览器中派发可取消 beforeunload 事件检查处理器，不等同于各平台原生刷新/关闭弹窗验收。

实际查看390手机、1440桌面顶部和320深色完整表单截图，核对中文换行、提示层级、长内容和底部操作；既有滚动按钮遮挡、键盘标签、失败重试、附件部分失败、报价及返回回归通过。上传导航专项首轮测试选到了手机隐藏的桌面导航，修正为可见导航后重跑。
