# 服务列表：无结果后的恢复路径

起点 c7724c5。本轮任务：客户搜索或组合筛选后看不到工单时，能判断原因并恢复到全部记录。

## 设计依据与实现

实施前阅读 Apple 官方 Search fields：https://developer.apple.com/design/human-interface-guidelines/search-fields.md 。采用清晰搜索范围、即时结果、清除入口和默认宽范围原则，适配现有 Web 品牌。

- 显示结果数量、服务类型与状态范围；“清除搜索”只清除关键词，保留类型和状态。
- 有记录但无匹配时，提供“重置全部条件”，同时清空关键词与两种筛选，恢复搜索框焦点。
- 账号确实无记录时，说明申请后的进度入口、线下工单关联处理方式，并提供“申请维修”。不虚构业务记录。
- 修复深色服务卡片变量的 scoped CSS 选择器失效，选中服务类型使用语义色背景和高对比文字；类型按钮至少 44px 高。

## 验证

Vue 类型检查及生产构建通过；既有 31 项 Node 行为回归通过。真实 Chromium 隔离 API fixture 的服务列表/报价/详情与维修申请脚本均在 320、390、1440px 通过；最终样式修改后重跑服务进度三宽测试通过。覆盖组合筛选、长中文搜索、清除与重置、结果数、焦点恢复、真正空账号至申请表导航，以及既有错误重试、返回、直达链接、迟到响应、报价确认/取消与下载链路。

实际查看手机浅色、390/320 深色无结果及桌面空账号截图，检查换行、按钮、底部导航与横向溢出。截图发现浅底浅字后修正；新增深色选中类型文字对比检查通过（按祖先背景合成半透明色，阈值 4.5:1；初版测试未合成透明度导致误报，已修正）。这不代表全站对比度审计完成。截图仅为隔离 fixture，不是后端端到端或真实业务验收。
