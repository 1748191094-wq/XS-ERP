服务管理系统 - 本地多端部署

主机：
1. 将 host.env.example 复制为项目根目录 .env。
2. 设置至少 24 位的 SYNC_SHARED_SECRET。
3. 双击“启动主机.cmd”。
4. 在管理页面查看本机局域网 IP。

终端：
1. 每台终端解压一份独立程序，不要复制主机 repair_management.db。
2. 将 terminal.env.example 复制为项目根目录 .env。
3. 填写唯一的 SYNC_NODE_NAME、主机 IP 和同一同步密钥。
4. 双击“启动终端.cmd”。
5. 第一次同步后，主机的客户、设备、工单、报价、库存和财务流水会下发到终端。
6. 各终端需建立与主机相同的用户名；密码和登录会话不会同步。

重要限制：
- 库存流水由主机按当前库存重算后再分发，终端不能直接覆盖主机余额。
- 财务流水合并后会重算关联工单的收款、成本和利润。
- 附件二进制文件不参与同步；PDF 和报告在各电脑按数据库重新生成。
- 冲突进入管理员“多端同步”页面，不会自动覆盖。
- 详细说明见 docs/LOCAL_MULTI_NODE_SYNC.md。
